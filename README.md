# Workshop Practice 3D Models of Mekerkera

This repository contains the complete SolidWorks 3D modeling project for the **Mekerkera Assembly**, created as part of workshop practice exercises. The project demonstrates fundamental CAD modeling techniques and assembly design principles.

## 📁 Project Structure

```
workshop practice drawing and models/
├── Assembly of Mekerkera.SLDASM    # Main assembly file
├── Base plate.SLDPRT               # Foundation component
├── Bridge.SLDPRT                   # Structural bridge component
├── Guide.SLDPRT                    # Guide mechanism component
└── Tongue.SLDPRT                   # Tongue component
```

## 🔧 Components Overview

### Main Assembly
- **Assembly of Mekerkera.SLDASM** - Complete assembly file containing all components in their final positions

### Individual Components
1. **Base plate.SLDPRT** - Foundation/base component that serves as the mounting surface
2. **Bridge.SLDPRT** - Structural bridge element that provides support and connection
3. **Guide.SLDPRT** - Guide mechanism component for controlled movement
4. **Tongue.SLDPRT** - Tongue component that interfaces with other parts

## 🎯 Project Objectives

This workshop practice project focuses on:
- **3D Modeling Fundamentals** - Creating complex geometric shapes and features
- **Assembly Design** - Understanding component relationships and constraints
- **Engineering Drawing** - Converting 3D models to 2D technical drawings
- **Design Intent** - Maintaining proper design relationships and parameters

## 🚀 Getting Started

1. **Clone or Download** the repository to your local machine
2. **Open SolidWorks** and navigate to the project folder
3. **Open the Assembly** file: `Assembly of Mekerkera.SLDASM`
4. **Explore Components** by double-clicking individual parts in the assembly tree
5. **Modify as Needed** for your workshop practice requirements

## 📖 Usage Instructions

### Viewing the Assembly
1. Open `Assembly of Mekerkera.SLDASM` in SolidWorks
2. Use the **FeatureManager Design Tree** to explore component hierarchy
3. Right-click components to **Hide/Show** or **Suppress/Unsuppress**
4. Use **Rotate**, **Pan**, and **Zoom** tools for detailed inspection

### Working with Individual Parts
1. Open any `.SLDPRT` file to examine individual components
2. Use **FeatureManager** to understand modeling techniques
3. Study **Sketch** and **Feature** relationships
4. Analyze **Design Intent** and **Constraints**

### Creating Drawings
1. From the assembly, go to **File > Make Drawing from Assembly**
2. Choose appropriate drawing templates
3. Add standard views (Front, Top, Right, Isometric)
4. Include **Bill of Materials (BOM)** and **Balloons**
