# Screw Down Stop Valve

This repository contains the complete design and documentation for a Screw Down Stop Valve project, including SolidWorks parts, assemblies, drawings, and specifications.

## Project Structure

- **`drawing/`** - Contains all SolidWorks drawing files (.SLDDRW)
- **`part/`** - Contains all SolidWorks part files (.SLDPRT) and assembly files (.SLDASM)
- **`pdf/`** - Contains PDF versions of all drawings and specifications
- **`Screw down stop valve Assembly.mp4`** - Video demonstration of the assembly

## Components

The valve assembly consists of the following main components:

1. **Valve Body** - Main body of the valve
2. **Bonnet** - Top cover of the valve
3. **Gland Tightening Nut** - Secures the gland assembly
4. **Gland** - Sealing component
5. **Sleeve** - Internal component
6. **Collar** - Structural component
7. **Steam with Screw** - Actuation mechanism
8. **Screwed Sleeve** - Threaded component
9. **Valve Seat** - Sealing surface
10. **Hand Wheel** - Manual operation component
11. **Stuffing Box Packing** - Sealing material
